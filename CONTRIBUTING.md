# Contributing to SentiFlow V6

We welcome contributions from researchers and developers!

## 🧪 Scientific Contributions
If you are an academic researcher, you can contribute by:
- Submitting **validated emotion-SEIR parameters** based on new datasets.
- Providing **benchmark datasets** for narrative contagion.
- Peer-reviewing the **Hierarchical Consensus weights**.

## 💻 Technical Contributions
- Improving the **Statistical Abstraction** layer for higher performance.
- Adding support for **local 7B models** in the tiered compute layer.
- Enhancing **Explainability** visualizations in the frontend.

## 🛡️ Security
Please report security vulnerabilities to security@sentiflow.org. Use secret managers for production API keys.
